# Portfolio Case Study: FieldTech Pro

**Project type:** AI-assisted web application · Electrical service estimating

**Live demo:** https://jbyerstemp-jpg.github.io/fieldtech-pro/

**Problem:** Small service contractors often need a quick, readable way to turn labor and material costs into an initial estimate.

**Solution:** A lightweight, responsive calculator with labor hours and rates, material markup, fees, optional tax, and a printable estimate summary. It works without registration or a backend.

**My contribution:** Identified the problem from hands-on electrical and equipment-maintenance experience; defined the requirements, calculation example, and usability priorities; directed AI-assisted implementation and GitHub publication.

**Technology:** HTML, CSS, JavaScript, GitHub Pages, GitHub Actions, Node.js built-in test runner.

**Quality controls:** Automated tests cover the example estimate, material tax, invalid negative values, recalculation, and resetting. The app clearly identifies itself as a demonstration rather than commercial estimating software.

**What I would build next:** Saved estimates, line-item materials, PDF export, contractor branding, mobile-first job intake, and location-specific tax handling.

**Roles of interest:** AI-assisted web development, technical implementation, automation, QA, and software support for field-service businesses.

**Transparency:** The code was produced with AI assistance. This case study describes project ownership and domain contributions, not a claim of independently writing all source code.

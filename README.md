# FieldTech Pro — Electrical Estimate Builder

A responsive, browser-based electrical service estimate calculator. Created as an **AI-assisted portfolio demonstration** informed by practical electrical trade experience.

## Features
- Editable labor hours and hourly rate
- Material cost and percentage markup
- Other fees and optional materials-only sales tax
- Instant itemized total
- Printable estimate summary
- Responsive layout; no server, accounts, dependencies, or stored customer data

## Live demo
Once GitHub Pages is enabled: https://jbyerstemp-jpg.github.io/fieldtech-pro/

## Run locally
Open `index.html` in a modern browser. No installation required.

## Example
4 labor hours × $95 = $380; $175 materials + 20% markup = $210; $35 other fees; 0% tax; **$625 total**.

## Limitations
This is a demonstration, not commercial estimating software. It does not calculate permits, labor burden, discounts, complex tax jurisdiction rules, or code compliance. Validate inputs and applicable taxes before relying on any estimate. Customer details remain in the current browser page and are not sent to a server.

## Development approach
Project requirements and domain context supplied by an electrical-industry professional. Implementation is AI-assisted; do not interpret this project as a claim of independently authored code.
